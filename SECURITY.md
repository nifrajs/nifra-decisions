# Security policy

Please do not open a public issue for a suspected vulnerability. Report it privately to the maintainers with a minimal reproduction, affected package and version, impact, and a safe contact path.

Do not include production payloads, credentials, API keys, or personal data in the report.

Nifra Decisions is designed to fail closed, but host applications remain responsible for authentication, authorization, tenant isolation, provider data policy, secret management, retention, and human review.
