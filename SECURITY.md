# Security policy

Please do not open a public issue for a suspected vulnerability. Use the repository's private GitHub Security Advisory form:

https://github.com/nifrajs/nifra-decisions/security/advisories/new

Include a minimal reproduction, affected package and version, and impact. If the advisory form is unavailable, contact the maintainers through a private channel rather than sharing sensitive details in a public issue.

Do not include production payloads, credentials, API keys, or personal data in the report.

Nifra Decisions is designed to fail closed, but host applications remain responsible for authentication, authorization, tenant isolation, provider data policy, secret management, retention, and human review.
